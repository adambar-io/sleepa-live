# sleepa live

Every NFL game this week on one page, updating live: score, clock, possession, timeouts, down and distance on a
field-position bar, the last play, ESPN win probability, pass / rush / receiving leaders and the score by quarter.

**Open it:** https://adambar-io.github.io/sleepa-live/

Coming next: a live play-by-play feed for each game, then enter a Sleeper username to see your players and your
opponents' players marked on every play, with fantasy points in each league's scoring.

A sibling of [sleepa](https://github.com/adambar-io/sleepa). One static page, no server, no tracking, no
third-party scripts. Game data comes from ESPN's public scoreboard. Not affiliated with the NFL, ESPN or Sleeper.
